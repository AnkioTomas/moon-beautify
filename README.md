# 月华 · Moon Beautify

月读（Moon）的美化扩展。给 [月读（Moon / book.koplugin）](https://github.com/AnkioTomas/moon) 的首页加一组纯展示的「吧唧」组件，同时在外观里面有组件背景/边框，组件合并，底栏图标这些功能。

**不联网、不改月读本体**。所有补丁都是运行时轻量替换且带兜底——月读升级导致接口变化时，最多是功能失效退回原生外观，不会影响启动。配置存在扩展自己的 `settings/ext.beautify.lua` 里，卸载插件不丢配置。

当前版本 **0.1.2**（见 `_meta.lua`）。下载见 [Releases](../../releases)，或直接 `Code → Download ZIP`。

装了 0.1.2 之后就不用手动换文件了：**设置 → 外观 → 月华美化 → 检查更新** 会直接对比 GitHub 上的最新 Release，弹窗里能看到更新日志，点「下载并安装」就地替换并自动重启；启动后每天也会静默查一次。

## 功能一览

### 🎖️ 吧唧组件（最多 4 个独立实例）

像手机上的电子徽章：拟真外观，全部像素级合成。

| 能力 | 说明 |
|---|---|
| **形状** | 圆形 / 圆角 / 直角，倒角、侧影、特效遮罩跟着形状走 |
| **尺寸** | 小 / 中 / 大（占位高度按比例报，改尺寸不会把整页排版顶乱） |
| **图片** | 固定一张，或选一个文件夹（每天一张 / 每次刷新随机） |
| **动图** | GIF / 动态 WebP 逐帧播（0.8 秒一帧，墨水屏节奏；帧多了自动限缓存） |
| **慢速旋转** | 约 24 秒一圈，逐帧平滑推进，不是老式的 90° 跳一下 |
| **动态特效** | 细闪 ✨、雨滴 🌧️、星星 ⭐，可多选叠加 |
| **外圈环** | 本体外面再画一圈：双线（纯程序绘制，任意尺寸不发虚） |
| **叠加素材** | 一张透明 PNG 压在照片上，自动按吧唧形状裁切 |
| **贴图格** | 8 格田字摆法，每格放一张自己的图（详见下文显示规则） |

动画为墨水屏优化：底图只在「角度/尺寸/素材变化」时重算一次，每帧开销约一次 blit + 几百次 setPixel，刷新节奏 0.8 秒/帧，三种特效坐标完全确定性——加帧、换帧都不会闪烁错位。

**贴图显示规则**：单独一行（满宽）时 8 格全显示；与其他组件并排（半宽）时只显示中间两列（2、3、6、7 格），四角格子不画——只给四角配图时整块自动隐藏，不留空位。

### 🎛️ 外观增强（设置 → 外观 → 月华美化）

- **底栏图标**：把月读底栏任意格子的图标替换成自己的图片（建议方形单色 PNG）
- **图标顺序**：调整底栏图标的先后（逐格上移 / 下移），一键恢复月读默认排列
- **组件背景**：给任意首页组件垫一张背景底图，支持「内容提亮」调节不透明度；**填充方式**可选拉伸 / 填满（裁边不变形）/ 居中（完整不裁）/ 平铺（小花纹重复）
- **组件花边**：给单个首页组件叠一圈花边框（透明 PNG，中间镂空不挡内容）
- **并排组合**：月读原生布局是严格竖排，这里可以把同一页的两个（或更多）组件合成一行、宽度均分；行高取组内最高者，搭档不在同页时自动退回原生排版，分页时同组成员保证不被拆开

### 🔄 自动更新（设置 → 外观 → 月华美化 → 检查更新）

- **手动检查**：点「检查更新」对比 GitHub 最新 Release，有新版就弹窗显示更新日志，点「下载并安装」就地替换并自动重启
- **自动检查**：进月读后每天静默查一次，没网或没新版完全无感；不想被打扰可在设置里关掉
- **发版约定**：GitHub Release 打 tag `vX.Y.Z`，附件 `moon-beautify-X.Y.Z.zip`（更新器按这个约定找包）

### 💾 主题包（设置 → 外观 → 月华美化 → 主题）

进入后是一整页：上半部分「保存与导入」，下半部分「已导入主题」列表（每行显示图片张数和占用空间，当前用的标「应用中」，改过设置则标「应用中（有修改）」）；点某行可选应用 / 导出 / 删除，操作后列表自动刷新。

导入 zip 只是归档进列表，**不会立刻生效**，要再点该主题选「应用」才切换样式。

固定目录 `.moon/beautify/themes/<主题名>/`，每个主题是「配置 + 图片」一套：

```
.moon/beautify/themes/chiikawa1/
    theme.lua    -- 配置，图片写成 @assets/xxx.png 相对引用
    assets/      -- 图片素材
```

- **当前配置保存为主题**：起个名字（中英文都行，如 `主题1`），把当前整套配置连图片快照下来；重名会提示「该名称已被占用」，不会覆盖旧主题
- **应用主题**：彻底替换当前配置为该主题原样（主题里没有的外观键会清掉），提示「已使用该主题」
- **导出主题 zip**：`chiikawa1.zip` 里包含 `theme.lua` + `assets/`，直接发给对方
- **导入主题 zip**：选 `.zip` 即解压到固定主题目录，图片路径自动改写成对方本机路径，导入后可直接使用
- **删除**：整目录递归删除（配置 + 图片一起清），当前正在用的主题会拒绝删除并提示「应用中删除失败」

不用主题时，各处照旧可以任意选图（自定义路径）；用了主题，图片一律走固定目录，换设备/换模板都不怕路径对不上。

### 🗂️ 其他细节

- **选图器目录记忆**：装了本扩展后，月读所有选图器（壁纸/锁屏/吧唧/组件背景）共享「上次目录」，不用每次从主目录翻起
- **图标即图片**：任何接受 `Icon` 的地方，name 写成图片路径就自动画图（被底栏替换和组件背景内部使用）
- **降级自处理**：特效合成失败自动退回最朴素的圆图；布局接管失败自动退回原生竖排；没有配置时补丁零行为

## 安装

1. 需要 KOReader **2026.07+** 且已安装月读（book.koplugin）
2. 从 [Releases](../../releases) 下载 `moon-beautify-<版本>.zip` 并解压（或 `Code → Download ZIP` 后解压）
3. 把解压出来的 **`moon-beautify.koplugin` 文件夹**整个放进 KOReader 插件目录（与 `book.koplugin` 同级）
4. 重启月读，在「拓展」页启用 **月华 / Moon Beautify**
5. 首页长按空白处进入编辑态 → 添加 → 选 **吧唧 / 吧唧 2 / 吧唧 3 / 吧唧 4**

> 月读的首页组件按 id 唯一，四个吧唧就是四个独立实例：各有各的图、形状、特效、贴图与转动设置。

## 快速上手

1. 编辑态添加一个吧唧 → 长按它 → 右上角齿轮 → 选一张图
2. 想要每天换图：图片 → 图片来源 → 文件夹里挑一张 → 选目录 → 换图节奏选「每天一张」
3. 想让时钟和吧唧挤一行：设置 → 外观 → 月华美化 → 并排组合 → 新建组合 → 依次选两个组件
4. 底栏图标换成自己的：设置 → 外观 → 月华美化 → 底栏图标 → 选格子 → 选一张图

首页壁纸、主题色板请用月读自带的设置，本扩展不重复。

## 已知注意事项

1. **动画要付出墨水屏的代价**：转动或开特效时约每 0.8 秒一次局部刷新，残影程度因机器而异。建议真机上先用「不转」或只留一种特效
2. 转动时每次角度变化会重算底图（旋转 + 倒角 + 高光 + 叠加素材），大尺寸快转在低端机可能吃力
3. 组件是纯展示的，点按无动作
4. 目前只设置 4 个吧唧

## 目录结构

```
moon-beautify/
├── README.md
├── LICENSE
└── moon-beautify.koplugin/     # ← 这个文件夹整个放进插件目录
    ├── main.lua                # 入口（月读扩展约定：空容器）
    ├── moon_source.lua         # 扩展描述：组件注册 + 补丁安装时机
    ├── _meta.lua               # 名称 / 版本 / 描述
    └── moonbeautify/
        ├── badge.lua           # 吧唧合成器（SDF 形状 / 倒角 / 高光 / 旋转 / 动画节拍）
        ├── bg.lua              # 组件背景渲染（填充方式 / 内容提亮）
        ├── deco.lua            # 花边与透明 PNG 渲染缓存（按路径 + 尺寸缓存）
        ├── effects.lua         # 细闪 / 雨滴 / 星星特效层
        ├── patch.lua           # 底栏图标 / 图标顺序 / 组件背景 / 花边 / 选图器记忆等运行时补丁
        ├── settings.lua        # 设置界面（编辑态齿轮 + 设置页外观入口）
        ├── rows.lua            # 并排布局（接管 layout.build / paginate，带兜底）
        ├── slots.lua           # 8 格贴图（田字 / 并排自适应）
        ├── view.lua            # 组件视图（背景叠层 / 占位 / 圆图 / 贴图挂载）
        ├── theme.lua           # 主题包（保存 / 应用 / 导入导出 / 内容哈希比对）
        ├── update.lua          # 自动更新（对比 GitHub Release，下载后就地替换并重启）
        ├── zip.lua             # zip 解包（主题导入用）
        ├── pick.lua            # 图片枚举与「每天一张 / 随机」挑选
        └── store.lua           # 配置存取（settings/ext.beautify.lua）
```

本包不含演示素材；贴图、叠加素材、底栏图标都需要自备图片。
